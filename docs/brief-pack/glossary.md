# Glossary

> Plain-language meaning of the words used in the pack. Decks and videos should use these words, not the internal ones.

Part of the [Product Brief Pack](index.md).

| Word | Meaning |
| --- | --- |
| **Band Studio OS** | The working title of the product. Not the final name |
| **Driver** | The one band member who runs the band's promotion. The only daily user in version 1 |
| **Bandmate reviewer** | A band member who approves or vetoes the material from a link, without an account |
| **Gig campaign** | All the promotion material for one show: flyer, stories, post, captions |
| **Pre-gig pack** | The campaign material made before the show. The only pack in version 1 |
| **After-the-gig material** | Thank-you posts and highlight reels made after the show. Not in version 1 |
| **Identity setup** | The short "who are we" step: name, style, how rough, what never to look like, a few reference images. Also called the identity studio in the inception documents; version 1 has a light version |
| **Grit setting** | A "how rough or how clean" choice that steers the look. In the newer design it became a few either-or taps |
| **"Never like this" list** | What the band does not want to look like (called the anti-moodboard in the inception documents) |
| **Approval gate** | The rule that nothing is exported until bandmates approve it |
| **Export folder** | A ready-to-post folder of finished images, a captions file and a suggested posting plan |
| **Connector** | A later add-on that links the product to another service, such as posting to Instagram or a reach partner |
| **Pay per campaign** | Paying a set price for each gig campaign, instead of a monthly fee |
| **Free pilot** | The first 5 to 10 bands use the first version for free, in return for feedback |
| **Driver interviews** | Conversations with 8 to 10 Italian band drivers to learn if the problem is real. Designed, not run |
| **Blind "is this us?" test** | Bands compare our output with their own flyer and with Canva or Simplified output without being told which is which |
| **Fake-door price test** | A real-looking offer to see if people would commit money, before anything is built |
| **Decision point** | A moment when Ale chooses to go on, reshape or stop, based on evidence |
| **Approved campaigns per month** | The main success measure: gig campaigns that all required bandmates approved and the driver exported |
| **Working title** | A name used for now, expected to change |
| **Desk research** | Reading what is already published, as opposed to talking to or testing with real people |
| **Needs primary research** | Desk research could not settle it; only real bands can. See the [status tags](index.md#how-to-read-the-status-tags) |
